## 🚀 Особенности

| Фича | Описание |
| :--- | :--- |
| ⚡ **Производительность** | Адаптировано под слабое "железо". Работает там, где тормозят браузеры. |
| 📺 **Android TV UI** | Полная поддержка управления с пульта (D-Pad). |
| 🚫 **Без рекламы** | Проект распространяется бесплатно и без встроенной монетизации. |
| 🤖 **Технологии** | Разработано на базе Google JetStream. |

* **Поддержка:** Обновления выходят исходя из свободного времени и возможностей разработчика.
